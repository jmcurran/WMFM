# Stage 48.10: Student-friendly explanation feedback

Stage 48.10 revises the feedback shown after a student checks an explanation.

The grading object and developer diagnostic report remain unchanged. The student panel now translates internal rubric metrics into concise, actionable language rather than exposing generic scoring-system descriptions.

The panel uses the headings:

- What you did well
- What you need to revise/improve

The feedback omits the generic overall-score loss row, removes duplicated dimension-level comments, and limits the display to four strengths and three revision priorities. Detailed scoring evidence remains available through developer diagnostics.
